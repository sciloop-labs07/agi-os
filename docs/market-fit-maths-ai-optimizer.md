# Maths AI → Skyloop Market Fit Optimization Bridge

The private `/market-fit` route contains a bounded scenario optimizer that borrows Maths AI’s candidate-search pattern without importing theorem or proof authority into business decisions.

## Boundary

Money Universe remains the macro source of truth. Market Fit remains the source of truth for funnel, API cost, revenue, retention, margin, runway, and break-even. The optimizer clones both inputs for every candidate and never mutates either source. Candidates are previewable, but only an explicit human action applies one to the private preview.

## Ranking and evidence

The first objective is a visible balanced score across activation, retention, paid conversion, gross margin, runway, API efficiency, evidence quality, and assumption safety. Weights are editable. Unverified API prices produce `needs-evidence` candidates and a zero evidence/profitability contribution; the optimizer never invents financial outputs. Invalid rates, negative values, invalid macro ranges, and malformed model mixes are rejected.

## Operational boundary

The search is local, deterministic, bounded, exportable, and simulation-only. It does not add APIs, database entities, authentication, billing, campaigns, external price ingestion, theorem generation, or deployment. Existing Maths AI theorem and proof portals remain independent. Use `/maths-ai` for deeper mathematical research and `/market-fit` for human-supervised economic scenario review.

## Rollback

The bridge is additive: remove the optimizer panel import/mount and the optimizer contract/engine exports, leaving the existing Market Fit and integrated Money Universe simulator intact. No migration or destructive rollback is required.
